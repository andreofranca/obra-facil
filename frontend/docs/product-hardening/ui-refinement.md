# Refinamento de UI

Melhorias implementadas:
- O layout de profissionais em destaque ajustou grid e espaçamentos internos de cartões visando coesão.
- Tags de \`Novo na plataforma\` garantem que cartões sem reviews fiquem harmoniosos no grid, sem quebrar o layout.
- Integração da cidade e estado mantiveram a estrutura unificada (ícone + texto) na tipografia correta.
