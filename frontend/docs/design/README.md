# ObraFácil Design System

Bem-vindo à documentação oficial do Design System do **ObraFácil** (Fase UX.2.1).

Este repositório de documentação contém todas as fundações visuais e diretrizes técnicas para garantir que qualquer desenvolvedor ou designer consiga expandir a plataforma de forma coesa, escalável e com padrão visual de produto premium.

## Índice da Documentação

- [Brand Guidelines](./Brand_Guidelines.md) - Personalidade, tom de voz e uso do logo.
- [Color System](./Color_System.md) - Paleta de cores oficial e tokens semânticos.
- [Typography](./Typography.md) - Escala tipográfica e pesos.
- [Spacing System](./Spacing_System.md) - Escala de espaçamentos e grids.
- [Elevation System](./Elevation_System.md) - Sombras e profundidade (Z-index).
- [Component Guidelines](./Component_Guidelines.md) - Regras para botões, inputs, cards, etc.
- [Motion Guidelines](./Motion_Guidelines.md) - Tempos de transição e animações.
- [Accessibility](./Accessibility.md) - Contraste, navegação por teclado e ARIA (WCAG 2.2).
- [Design Decisions](./Design_Decisions.md) - Histórico e o "porquê" das decisões arquiteturais tomadas na Sprint UX.2.1.

## Visão de Longo Prazo

Este Design System é a base **oficial e inegociável** de todas as próximas telas, incluindo Login, Cadastro, Perfis e Dashboards. Nenhuma interface deverá ser construída com HTML hardcoded e variáveis estáticas flutuantes. Use os Tokens.
