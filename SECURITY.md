# Política de Segurança

## Versões Suportadas
Atualmente, apenas as versões mais recentes (ex: `v0.24.x-beta`) recebem atualizações imediatas de segurança.
Acompanharemos as vulnerabilidades críticas descritas pelo `npm audit`.

## Como relatar uma vulnerabilidade
Se você descobrir um problema de segurança (seja quebra de autorização no JWT, exposição acidental de tokens de API, ou problemas de XSS), **NÃO** crie uma Issue pública no repositório.

Por favor, reporte o problema de forma privada para a equipe de manutenção através dos canais internos do projeto ou pelo e-mail oficial (a ser definido). Responderemos à denúncia o mais rápido possível e gerenciaremos o `hotfix`.
